# La Sinistra storica (1876-1896)

Grafico animato e interattivo sui temi della Sinistra storica, da Depretis a Crispi.
Sei temi orbitano attorno al 1876: tocca (o seleziona con la tastiera) un tema per leggerne il dettaglio.

Un solo file, `index.html`: nessuna dipendenza, nessuna build. Supporta tema chiaro e scuro e rispetta `prefers-reduced-motion`.

## Pubblicazione con GitHub Pages

1. Crea un nuovo repository su GitHub (ad esempio `sinistra-storica`).
2. Carica `index.html` e `README.md` nella radice del repository.
3. Vai in **Settings → Pages**.
4. In **Build and deployment**, scegli **Deploy from a branch**, branch `main`, cartella `/ (root)`, poi **Save**.
5. Dopo un minuto la pagina sarà online su `https://<tuo-utente>.github.io/sinistra-storica/`.

## Prova in locale

Apri `index.html` con un doppio clic nel browser.
